# STRIDE
## Sigla para :
- Spoofing
- Tampering
- Repudiation
- Information Disclosure
- Denial of Service(DOS)
- Elevation of Privilege(EoP)

Uma arquitetura de uma aplicação web pode ter essas seis vunerabilidades

## Spoofing
Falsificação de identidade, alguém tentando se passar por outra pessoa
## Tampering
Adulteração dos dados (Violação de integridade)
## Repudiation
Negar fazer a ação
## Information Disclosure
Vazamento de informações
## Denial of Service(DOS)
Negação de Serviço,o sistema fica indisponivel
## Elevation of Privilege(EoP)
Elevação de privilegios, dar mais permissão a alguém sem necessariamente merecer

Podemos utilizar uma IA para simular analistas de segurança e criar modelos de ameças detahados
